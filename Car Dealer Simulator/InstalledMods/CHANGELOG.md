# Installed Mods — Changelog

Released versions only.

## 1.0 - First Release

First public release. Installed Mods adds an INSTALLED MODS button to the game's title menu. It opens a page listing the UE4SS mods you have installed.

- See each mod's name, whether it's on or off, and its version (from the mod's mod-support.json, or the version it printed in UE4SS's log).
- Turn mods on or off and press Apply. The change takes effect the next time you start the game, and a box offers to quit the game now.
- Only a mod's enabled.txt is changed, and only when you press Apply. Rows it can't switch say why.
- UE4SS's own built-in mods are left out of the list.
- Report a Bug and Request a Feature buttons at the top of the page.
